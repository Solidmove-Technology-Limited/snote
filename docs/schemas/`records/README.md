SNote Verification Records

This directory contains public verification records for systems, products, services, and technology assets reviewed under the SNote verification process.

Purpose

SNote records the evidence and decision status of items associated with SOLIDMOVE TECHNOLOGY LIMITED.

A record may document an item as:

- Unverified
- Pending Verification
- SNote Verified
- Official SolidMove Product
- Rejected
- Historical
- Not Owned by SolidMove

Public Repository Rule

This repository is public.

Do not store confidential evidence in this directory.

Never commit:

- passwords;
- API keys;
- access tokens;
- bank account information;
- private contracts;
- personal identification documents;
- confidential financial information;
- private customer information;
- private security records.

Sensitive evidence must remain in an appropriate controlled storage system.

Verification Authority

SNote records verification status. It does not independently create company ownership or corporate authority.

Official SOLIDMOVE TECHNOLOGY LIMITED product status requires the required technical verification, evidence review, SNote verification, and authorized founder approval.

Verification Principle

«No sufficient evidence + no SNote verification + no authorized approval = no official SolidMove product status.»
